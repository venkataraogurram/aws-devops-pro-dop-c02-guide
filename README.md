# AWS Certified DevOps Engineer - Professional (DOP-C02) Study Guide

**Version:** v1.1 (Nov 2026) | **Exam:** Tue, Dec 29, 2026

Complete material for DOP-C02 in one repo, one file per chapter. Built from the official [DOP-C02 exam guide](https://docs.aws.amazon.com/aws-certification/latest/devops-engineer-professional-02/devops-engineer-professional-02.html) (all 6 domains, every task statement, the in-scope services list). Facts checked against AWS documentation as of Nov 2026.

## Start here
1. Read [Chapter 0](00-exam-strategy.md) (exam format and how to read questions).
2. Follow the [46-day study plan](09-study-plan.md) one row per day.
3. Do the matching [lab](10-hands-on-labs.md) for each topic.
4. Log every wrong practice answer in the [mistakes log](mistakes-log.md).
5. Last week: only [Chapter 7](07-service-comparisons-numbers.md), the [cheat sheet](11-final-cheat-sheet.md), and your mistakes log.

## How each domain chapter is laid out
- **What it is**, in simple words.
- **Must-know facts** (tables, YAML/JSON samples, diagrams).
- **Traps** the exam uses.
- A **"scenario → answer" quick-map** at the end. Cover the right column and test yourself.

Diagrams use Mermaid and render on GitHub. Practice answers are hidden behind "Answer" toggles.
